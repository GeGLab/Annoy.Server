Continuação após adiar Windows/auditoria: testes de mídia isolam estados por chamada, impedem chaves no outbox/backup e removem o registro inteiro ao encerrar. O pipe nativo passou a limpar buffers mutáveis consumidos/escritos e ignorar erro de escrita de processo antigo após reinício. A etapa de distribuição acrescentou `build.electronFuses` no Client, `scripts/verify-native-package.mjs` e checagens Linux no workflow: binário real recusou flags padrão e cópia adulterada. O benchmark `native/annoy-crypto/examples/benchmark_group.rs` exercita capacidade nativa limitada, sem SFU/frames. Essas etapas não habilitam mídia segura nem validam instaladores.
