## Annoy server 0.7.1

- **Atualizações pelo app:** o administrador da instância vê a versão instalada e a mais nova em Administrar instância → Atualizações, atualiza com um clique e liga ou desliga a atualização automática. Quem estiver em chamada volta sozinho depois do reinício.
- O contêiner `updater` agora roda sempre ao lado do servidor (a atualização automática começa desligada). Quem usava `COMPOSE_PROFILES=autoupdate` continua com ela ligada. `ANNOY_AUTO_UPDATE=on` liga por padrão até o admin escolher no app.
- A versão informada pelo servidor vem do `package.json` (antes mostrava 0.6.0 na 0.7.0).

**Para ativar uma vez:** na pasta do annoy-server, `git pull && docker compose up -d`. Depois disso, as próximas atualizações são feitas pelo app.
