# Annoy Server 0.11.0-alpha.1

## Client mínimo obrigatório
- A versão mínima padrão do Client passa a ser 0.11.0-alpha.1.
- O gateway recusa versões antigas e versões ausentes ou inválidas, informando que é necessário atualizar.
- Clients iguais ou superiores ao mínimo continuam aceitos.

Atualize os Clients antes de atualizar o Server. A configuração explícita ANNOY_MIN_CLIENT_VERSION continua disponível para operadores.

## Distribuição
- Imagem Docker: ghcr.io/geglab/annoy-server:0.11.0-alpha.1.
- A release atualiza também os canais Docker latest e alpha.
