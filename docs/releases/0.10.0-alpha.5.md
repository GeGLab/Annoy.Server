# Annoy server 0.10.0-alpha.5

Works with Annoy 0.10.0-alpha.5 and the Annoy cloud from the same date.

## User settings belong to the Annoy account
- With Annoy accounts (`ANNOY_ACCOUNT_MODE=global`) the server keeps only server settings. Profile contacts, activity history, the Steam link and Discord sign-in answer `410 moved_to_annoy`; the rows the server held are deleted once at start. Name, bio and photo stay as a copy the app writes from the Annoy profile. No session is touched.
- The server reports its servers, owners and members (Annoy IDs) to the Global, for "friends and communities in common" contacts and for account deletion.
- Annoy account deletions reach the server through the Global: servers where the person is the only member are deleted, the person leaves the others, and their messages stay with the author "Usuário desconhecido".

## Servers
- Leaving a server keeps your messages there, with the author "Usuário desconhecido".
- Each server has its own sticker pack (`MANAGE_STICKERS`, 60 per server, `servers.sticker_limit` overrides). Public sticker images and info for DMs and other servers.
- A sticker link can be a reaction (`POST /api/channels/:id/messages/:messageId/reactions`).

## Operations
- `annoy-admin.sh restart` applies `.env` changes without downtime.
- The Android app origin `https://annoy.localhost` is allowed by default.
- Every remaining "distopic" identifier is now "annoy": the database file is `annoy.db` (renamed automatically) and the compose volume is `annoy-data`; `DISTOPIC_*` variables still work.
