# Annoy Server 0.8.0

- Sessões de voz pertencem à conexão com o servidor. Fechar o gateway remove a sessão imediatamente; não há período de tolerância nem retomada de sessões Cloudflare antigas.
- O encerramento normal do processo, inclusive numa atualização, encerra chamadas privadas e revoga faixas publicadas e recebidas no Cloudflare. O servidor aguarda as tentativas de revogação por até 5 segundos; indisponibilidade da API externa não impede a limpeza local.
- A transferência de chamadas privadas entre processos foi removida. Dados de transferência de versões anteriores são ignorados.
- Uma publicação que termine depois da perda da conexão é revogada e não recria o participante desconectado.

Também incorpora as alterações recentes da `main`: reações persistidas e sincronizadas, imagens animadas de perfis e servidores, atividades de grupo com controle de acesso e configuração autenticada da busca GIPHY. As migrações de `message_reactions` e `servers.icon_url` são aditivas; mantenha o backup normal do diretório de dados antes de atualizar.

Atualize também o cliente para 0.8.0: ele fecha os transportes e libera dispositivos quando o gateway cai e detecta uma rede silenciosa após 10 segundos sem heartbeat confirmado. Um processo morto à força não pode executar limpeza remota; nesse caso o cliente é responsável pelo encerramento da mídia.

Os dois slots de atualização continuam existindo para trocar a API. Essa troca encerra mídia e não implica uma volta automática à voz.

Validação: `npm run typecheck` e `node --import tsx --test tests/*.test.ts`.
