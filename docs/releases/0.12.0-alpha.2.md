# Annoy Server 0.12.0-alpha.2

- Fixed integration requests failing for public IPv4 endpoints. IPv4 and IPv6 address filters are now independent, preserving the restrictions on private, local and mapped addresses.
- The community owner installs and manages integrations. Members can use installed integrations with the existing Use integrations permission, without individual acceptance.

Docker: `ghcr.io/geglab/annoy-server:0.12.0-alpha.2` (`alpha` and `latest` also receive this fix).
