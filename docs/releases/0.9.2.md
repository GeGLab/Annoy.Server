# Annoy Server 0.9.2

O servidor guarda o ID público da conta Annoy, assinado pelo Global. O admin liga um usuário existente a uma conta Annoy com `npm run account:link -- <usuário> <ID público>`. O próximo login dessa conta abre o usuário, com histórico e cargos. Exige o client 0.9.3 para enviar o ID.
