# Annoy Server 0.12.0-alpha.1

- **Store integrations per server.** The owner installs an integration from the Annoy Store (`PUT /servers/:id/integrations/:integrationId`) and gives its API key, which never leaves this server. `GET /servers/:id/integrations` lists them without the key.
- New permission `USE_INTEGRATIONS`. Members who have it call an installed integration in a channel with `/command` or `@Name`; the server calls the integration (public HTTPS only, no redirects, bounded answers) and posts the answer as a message marked with the integration's name and icon. Integration answers can't be edited and never call another integration.
- At most 20 calls per minute per server. The store copy of an installed integration is read again every hour; an integration removed from the store is removed from the server.
- Integration calls use devannoy's Ed25519 signatures and report usage to the Developers dashboard. Installed integrations register their server connections with the platform.
- New setting `ANNOY_STORE_URL` (default `https://devannoy.geg.dev.br`). Integrations are available in Annoy-account mode only; the gateway announces them with the `integrations` feature flag.
- Database: new table `server_integrations` and column `messages.integration`, added automatically on start.
