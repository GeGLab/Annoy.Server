## Annoy server 0.6.0

- Conexão de contas Steam por OpenID e consulta privada da atividade online, sem expor Steam ID ou credenciais a outros usuários. A consulta online usa a variável opcional `ANNOY_STEAM_API_KEY`.
- Transferência de propriedade para outro membro ativo e proteção contra exclusão de comunidades com outros membros pelo proprietário, inclusive pela interface administrativa.
- Presença manual Online, Ausente, Não incomodar e Invisível, com compatibilidade para clientes antigos.
- Usuários invisíveis publicam presença offline e atividades vazias, inclusive nos snapshots enviados a amigos. Voltar a ficar visível restaura a atividade atual.
- Contrato compartilhado atualizado para as melhorias do cliente, conservando o protocolo atual.

Inclui as melhorias de presença e privacidade de GuilhermeSDB.

A regra de sete dias offline permite remover uma conexão salva no cliente; não exclui dados remotos de uma instância indisponível.

Após a publicação, o workflow `docker` gera a imagem `ghcr.io/geglab/annoy-server:0.6.0` e atualiza as tags `0.6` e `latest`. Para atualizar uma instância: `docker compose pull && docker compose up -d`.
