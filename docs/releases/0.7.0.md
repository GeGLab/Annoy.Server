## Annoy server 0.7.0

- Novos tipos de canal: **Arquivos**, **Código**, **Theater** e **Song**. O esquema de canais é migrado automaticamente na primeira inicialização, sem perder dados.
- Canais de arquivos: cada envio precisa ter ao menos um arquivo.
- Canais de código: a instância clona um repositório Git externo (somente `https`, nunca endereços da própria rede), permite editar arquivos com detecção de conflito e faz status, diff, commit, pull, push e troca de branch. Tokens de acesso são usados por comando e nunca gravados. A imagem Docker agora inclui o `git`.
- Theater e Song: fila de reprodução sincronizada por canal (uploads, links diretos, YouTube e sites). Salas Theater também aceitam voz e transmissão de tela.
- Salas de voz temporárias: qualquer membro com permissão de conectar cria uma; ela é excluída quando todos saem ou após 10 minutos se ninguém entrar.

Clientes antigos continuam funcionando; os novos canais aparecem para eles como canais simples sem conteúdo.

Após a publicação, o workflow `docker` gera a imagem `ghcr.io/geglab/annoy-server:0.7.0` e atualiza as tags `0.7` e `latest`. Para atualizar uma instância: `docker compose pull && docker compose up -d`.
